# Contributing

Install `python -m pip install -e '.[dev]'` and run `python -m pytest -q` from the checkout root.

Describe the triggering input, tool evidence, and expected decision for agent changes. Add focused regression tests with fake model and network dependencies. Keep policy in the shared controller.

Do not commit credentials, private imagery, model weights, logs or generated reports. Document new configuration variables. Contributions are provided under the MIT license.
